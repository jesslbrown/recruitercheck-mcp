# MCP Server

Phase 1 TypeScript skeleton for the RecruiterCheck MCP server.

## Scripts

- `npm run dev`: TypeScript watch mode for local development.
- `npm run build`: Compile `src/` TypeScript into `dist/`.
- `npm run start`: Run the compiled server entrypoint (`dist/index.js`).

Notes:
- This package intentionally contains only baseline bootstrapping.
- Tool registration and scoring logic are handled in later phases.
